# AI Real Estate Market Intelligence Platform

Synthetic Metro Atlanta housing analytics project using Tableau, BigQuery-style SQL, GIS fields, and AI-style market summaries.

## What is included
- `data/synthetic_atlanta_housing_records.csv`: 27,000 realistic property listing records.
- `data/market_monthly_summary.csv`: monthly market KPIs for dashboarding.
- `sql/bigquery_schema.sql`: warehouse table and KPI view.
- `scripts/generate_market_summary.py`: automated market summary script.
- `docs/tableau_dashboard_blueprint.md`: Tableau dashboard layout and calculated fields.

## Portfolio angle
This project shows property data modeling, geospatial market analysis, affordability scoring, price-per-square-foot benchmarking, and automated market reporting for real estate decision-making.
